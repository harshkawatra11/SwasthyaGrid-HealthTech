Differences from the design docs and why:
- The funnel counts "approved" as any of approved, modified, dispatched or fulfilled (a recommendation that was modified before approval is still a decision made, not a stall).
- Sensitivity matrix model: a truck only "saves" a facility if it lands within 10% of that facility's remaining days of cover at the projected delay; this is stated in the card's Read caption since it is a simplifying assumption, not measured data.
- Options considered only fires for replenishment and stock_transfer types (bed_redirect and staff_transfer have no meaningful source options), per the archetype's own qualifier.
- The board is not literally drag and drop (a judge-facing decision desk, not an editable Kanban); moving a card to another column happens by approving, rejecting or the shipment completing, which matches "Approve, modify or reject" from the page description above the board.
